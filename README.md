# Data Analyst Internship – Task 10: Python EDA

## Dataset Used
Students Performance in Exams (Kaggle)

## Objective
Perform Exploratory Data Analysis (EDA) and detect outliers using Python.

## Tools Used
- Google Colab
- Python
- pandas, numpy, matplotlib

## Steps Performed
- Loaded dataset and checked structure
- Generated descriptive statistics
- Calculated missing value percentages
- Visualized distributions using histogram and boxplot
- Detected outliers using IQR method
- Created outlier flag column
- Handled outliers using capping
- Performed correlation analysis
- Exported cleaned dataset

## Deliverables
- task10_eda.ipynb
- cleaned_dataset.csv
- eda_findings.txt
